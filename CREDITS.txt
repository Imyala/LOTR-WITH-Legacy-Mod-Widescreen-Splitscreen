CHANGING A LINK OR A VERSION
---------------------------
Every file's header is written by witn_stamp.py. Edit the MODINFO table at the
top of it - title, version and guide URL per mod - and run:

    python witn_stamp.py

It replaces the header it wrote last time instead of stacking another one, so
it is safe to run as often as you like.
